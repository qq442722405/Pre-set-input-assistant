# 预置输入助手

Windows 鼠标右键预置输入工具。

## 本版本功能
- 系统托盘常驻。
- 托盘右键菜单只有：**设置、退出**。
- 点击托盘“设置”进入完整设置界面。
- 支持 Windows **开机启动**。
- **选择程序**：每个 EXE 单独保存自己的右键预输入内容。
- 每个程序的右键预输入默认关闭，需要单独勾选启用。
- 每个程序可以添加多条预输入内容。
- 每一条内容右侧都有：**删除、↑上移、↓下移**。
- 保存退出后立即保存配置。
- 鼠标右键时，预输入面板显示在原生右键菜单**右上方**，尽量不遮挡原菜单。
- 预输入面板为黑色主题、白色文字。
- 点击预置内容后，将文字输入到原来的输入位置。

## 设置使用顺序
1. 启动程序。
2. 右下角托盘图标右键 → **设置**。
3. 第一项勾选 **Windows 开机自动启动**（可选）。
4. 点击 **选择程序**，选择需要设置的 EXE。
5. 勾选 **启用此程序的右键预设输入**。
6. 添加预设内容，例如 `12345+ -`，每行一条。
7. 使用右侧 **删除 / ↑ / ↓** 调整内容。
8. 点击 **保存退出**。
9. 回到该程序，在输入位置右键即可看到对应的预输入。
