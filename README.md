# 预置输入助手

Windows 右键预置输入工具。

## 功能
- 系统托盘常驻。
- 托盘右键：设置、添加/删除预置内容、总开关、重新加载、退出。
- 每个 Windows 程序独立配置预置内容。
- 每个程序默认关闭右键预输入，只有在设置中单独开启才生效。
- 右键时在原生 Windows 右键菜单的右上方显示黑色、白字快捷输入面板，不覆盖原生菜单。
- 点击预置内容后恢复目标窗口并执行 Ctrl+V。
- 配置保存到程序目录 config.json。

## GitHub Actions
进入 GitHub 的 Actions，选择 `Build Windows`，点击 `Run workflow`。
构建完成后下载 Artifact `预置输入助手-Windows`。

## 第一次使用
1. 启动程序后托盘出现图标。
2. 右键托盘图标 → `设置每个程序的预输入`。
3. 点击 `添加程序`，填写目标程序 EXE 完整路径。
4. 添加该程序专用的预置内容。
5. 勾选 `在此程序中启用右键预输入`。
6. 回到目标程序右键即可看到独立的预输入面板。

注意：当前版本按目标窗口所属 EXE 路径区分程序，同一个 EXE 的不同窗口共用该 EXE 的配置。
